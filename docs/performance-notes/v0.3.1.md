# RustDroid Performance Notes: v0.3.1

`v0.3.1` changes the release checksum contract, not the runtime. Its timing
evidence therefore records the current public receipt path rather than
claiming a product-wide speed improvement.

## Reproducible CI samples

The table combines three successful full
[`reference-stack-fixtures`](../reference-workflows.md) matrices:
[`32911691564`](https://github.com/OthmaneBlial/rustdroid/actions/runs/32911691564)
and
[`32913034524`](https://github.com/OthmaneBlial/rustdroid/actions/runs/32913034524),
and
[`32914348192`](https://github.com/OthmaneBlial/rustdroid/actions/runs/32914348192).
Each row has three receipt samples (`n = 3`) for the same public source fixture.
Values are milliseconds as **mean ± sample standard deviation**; they cover
RustDroid's boot/reuse, install, and launch stages only, never the Gradle,
Flutter, or Expo build time.

| Public fixture | Boot | Install | Launch | Total |
| --- | ---: | ---: | ---: | ---: |
| Gradle Android | 7,221 ± 140 | 3,503 ± 64 | 3,497 ± 3 | 16,222 ± 194 |
| Flutter | 7,259 ± 181 | 4,362 ± 186 | 5,258 ± 107 | 18,881 ± 95 |
| Expo prebuild | 7,566 ± 401 | 4,909 ± 286 | 3,916 ± 55 | 18,392 ± 67 |

Both matrices use the checked-in workflow shape: GitHub-hosted
`ubuntu-22.04` with KVM, `test_avd`, API 35, x86_64 Google APIs, no snapshot,
headless rendering, and the `host-fast` profile. The receipts identify
RustDroid `0.3.1` and retain their package/activity, input digest, stage
timings, and raw JSON/HTML/JUnit/Markdown artifacts for review.

Three samples are enough to expose gross regressions and a measured spread; they
are not enough to make a universal timing promise. The fixture APKs are
deliberately different sizes, so compare a fixture only with its own future
samples. No Docker comparison is published because an equivalent Docker matrix
has not been measured under the same runner and APK conditions.

The second Flutter receipt had a transient empty API property even though the
workflow fixed the emulator at API 35. The checked-in action now retries that
read and its
[current-action contract](https://github.com/OthmaneBlial/rustdroid/actions/runs/32914433185)
requires a nonempty API field; that contract passed with API `35`.
